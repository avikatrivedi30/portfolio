3. **Projects**:
   - Add your own live demo links and repository links in the `<section id="projects">` block of `index.html`.

## 🌐 Free 1-Click Deployment Options

### Option 1: GitHub Pages (Recommended)
1. Push this folder to a GitHub repository named `portfolio` (or `<your-username>.github.io`).
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your site is live at `https://<your-username>.github.io` within minutes!

### Option 2: Netlify Drop
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `avika-portfolio` folder directly onto the page.
3. Your site gets deployed instantly with an SSL certificate.

### Option 3: Vercel
1. Run `npx vercel` in the folder or import the GitHub repository in your Vercel dashboard.
